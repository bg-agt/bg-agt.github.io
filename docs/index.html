    Ask in plain language

    Say “annotate these assemblies” or “which genes do these isolates share?”. A main agent works out the task and the files, then hands them to a specialist.

    Pipelines never change

    Agents only choose which preset pipeline to run and on which files. Commands, parameters and container images are fixed beneath the model.

    Fails visibly, never silently

    No reference genome? Only one genome for a pan-genome? The run stops and says what is missing, instead of returning a confident wrong answer.

    How it works

    One request in. Fixed pipelines underneath.

    A conversational main agent reads your request and routes it to one of four specialists. If a step depends on files you haven't produced yet, BG-AGT runs the upstream tools first. Ask for a pan-genome from raw reads and it runs SPAdes, then Prokka, then Roary.

    1. 1
      You ask

      Upload FASTQ, FASTA, GFF or GBK files and describe what you need.

    2. 2
      An agent routes

      It picks the preset pipeline and target files. Nothing else.

    3. 3
      The pipeline runs

      In its own container, with pinned versions. Results are ready to download.

    Prefer clicking? Use the graph builder.

    Connect tools on a canvas and run them without an agent. Runs go through the same run manager and the same chaining rules, so SPAdes → Roary is rejected.

    Ask about genes and proteins

    Questions like “what does gyrA do?” are answered from a UniProt lookup rather than from the model's memory.

    The tools

    Community-standard tools, pinned and containerized.

    Each tool runs in its own Docker container, pinned by image digest. There's nothing to install separately.

    Assembly

    SPAdes 4.2.0

    In
    Paired-end reads (FASTQ)
    Out
    Assembled contigs (FASTA)

    Annotation

    Prokka 1.15.6

    In
    Assembly (FASTA)
    Out
    GFF, GBK, proteins, feature table

    Pan-genome

    Roary 3.13.0

    In
    Two or more annotations (GFF)
    Out
    Gene presence–absence matrix, accessory genes

    Variant calling

    Snippy 4.6.0

    In
    Contigs (FASTA) + reference (GBK)
    Out
    Variants (VCF, table)

    More are planned: read and assembly quality control, species identification, MLST, AMR gene detection and phylogenetics.

    Bring your own model

    Use any LLM. The computation doesn't change.

    Models connect through one uniform interface, so you can swap providers without changing what is computed.

    API models

    Hosted models from providers such as OpenAI, Anthropic and Google. Because the model only chooses the pipeline and its files, smaller and cheaper models can do the job.

    Local models

    Open-weight models served by Ollama on your own machine. No API key, no per-token cost, and no sequence data leaves the premises.
